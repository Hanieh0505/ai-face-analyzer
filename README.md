# 🔍 AI Face Analyzer

A lightweight, fast, and modern web application built with Python for image processing, face detection, and AI-powered skin and appearance analysis reports.

## 🛠️ Tech Stack
- **Python**
- **Streamlit** (Web UI framework)
- **OpenCV & NumPy** (Image processing & face detection)
- **Groq API** (Fast LLM integration for AI reporting)

## 🌟 Features
- Automatic image quality and brightness check
- Real-time face detection and bounding box annotation
- AI-generated personalized care and styling report
